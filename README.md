# Vocabulary Bot

Telegram-бот для вивчення слів: вибір мови перекладу, категорії, власні слова,
AI-пояснення (Gemini, 5 запитів/тиждень) та сповіщення за розкладом.

## Структура

| Файл | Призначення |
|---|---|
| `main.py` | Хендлери, меню, APScheduler, запуск |
| `db.py` | Схема PostgreSQL (`users`, `words`, `user_settings`), стартові 10 слів, запити |
| `ai.py` | Інтеграція з Gemini API |
| `texts.py` | Тексти інтерфейсу uk / ru / en |
| `data/italian_words.csv` | Італійські слова зі слайдів «Ripasso» |
| `data/italian_vocab_guide.csv` | Італійські слова з Italian Study Guide (сторінки 2–12) |
| `data/italian_verbs.csv` | Дієслова з Italian Study Guide (сторінки 13–18), розкладені по підтемах |
| `seed.py` | Синхронізація CSV → база без запуску бота |
| `render.yaml` | Blueprint для Render (worker + PostgreSQL) |

## Локальний запуск

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env          # відкрийте .env і заповніть значення
python main.py
```

Linux / macOS:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # заповніть значення
python main.py
```

Файл `.env` бот читає сам — експортувати змінні вручну не потрібно.
Для локального запуску потрібна доступна PostgreSQL (`DATABASE_URL` у `.env`).

Токен бота — у @BotFather, ключ Gemini — у Google AI Studio.
Таблиці та 10 стартових слів створюються автоматично при першому запуску.

## Деплой на Render (24/7)

1. Завантажте папку в GitHub-репозиторій.
2. Render → **New → Blueprint** → оберіть репозиторій (підхопить `render.yaml`).
3. Задайте секрети `BOT_TOKEN` і `GEMINI_API_KEY`.
4. Бот працює як **Background Worker** (long polling), тому не залежить від вашого комп'ютера.

> Перед деплоєм перевірте актуальні тарифи Render: чи доступний потрібний вам план
> для worker і які обмеження має безкоштовна PostgreSQL (термін життя, розмір).

## Команди та меню

`/start`, `/add`, `/words`, `/quiz`, `/explain`, `/settings_interval`, `/language`, `/learn`, `/cancel` —
і ті ж дії через Reply Keyboard знизу.

## Як це працює

- **Мова (2.1):** inline-меню при першому запуску та через «🌐 Мова».
- **Що вчимо:** кнопка «🎓 Що вчимо» (або `/learn`) перемикає англійську / італійську.
  Для кожної мови свої 10 стартових слів, свої власні слова, AI-пояснення та сповіщення.
- **Слова (2.2):** «📚 Мої слова» — категорії; обрана категорія застосовується і до сповіщень.
- **Власні слова (2.3):** «➕ Додати слово» → слово → переклад → збереження у персональну базу.
- **AI (2.4):** атомарний ліміт у БД, 7-денне вікно від першого запиту; при перевищенні бот
  показує дату оновлення. Невдалий запит до Gemini не списується.
- **Вікторина:** кнопка «🧩 Вікторина» або `/quiz` — 10 питань: слово та 4 варіанти перекладу
  (3 хибні беруться з тієї ж добірки слів). Після відповіді показується правильний переклад і рахунок.
  Використовується обрана категорія; якщо в ній менше 4 різних перекладів, питання беруться з усіх слів.
- **Нічний режим:** з 22:00 до 09:00 сповіщення не надсилаються. Межі задаються змінними
  `QUIET_HOURS_START` / `QUIET_HOURS_END`, час — за `TZ_NAME`. Після 09:00 надходять сповіщення,
  чий час уже настав.
- **Сповіщення (2.5):** APScheduler щохвилини перевіряє `user_settings` і надсилає слово,
  якщо настав час. Інтервали: щогодини, 2 год, 4 год, раз на день, зранку/ввечері (9:00 / 20:00), вимкнено.
  Переклад приховано під спойлером.

## Категорії та підтеми

Код категорії `розділ_підтема` означає підтему розділу. Так працює розділ **«Дієслова»**:
у меню «📚 Мої слова» він показується як `📂 Дієслова`, а після натискання відкривається підменю:

| Код | Підтема |
|---|---|
| `verbs` | усі дієслова разом |
| `verbs_are` / `verbs_ere` / `verbs_ire` | дієслова на -ARE / -ERE / -IRE |
| `verbs_isco` | дієслова на -IRE з -isco (`capire (capisco)`) |
| `verbs_reflexive` | зворотні (Riflessivi) |
| `verbs_irregular` | неправильні дієслова (відмінювання в дужках біля слова) |
| `verbs_pp_avere` / `verbs_pp_essere` | Passato prossimo з avere / з essere (`mettere (messo)`) |
| `verbs_pp_irregular` | Passato prossimo: винятки (`aprire (ho aperto)`) |

Вибір розділу (`verbs`) охоплює всі його підтеми: слова з нього приходять у сповіщеннях і вікторині.
Щоб створити нову підтему, достатньо дати в CSV код виду `розділ_підтема` (наприклад `food_fruit`),
а назву додати в `CATEGORY_NAMES` у `texts.py`. Для звичайних категорій без підтем підкреслення в коді не використовуйте.

Вікторина не ставить поруч із правильною відповіддю варіанти, що по суті збігаються з нею за змістом
(наприклад «спокійний» і «спокійний (тихий)»).

## Як додати слова в базу

**Спосіб 1 — через CSV (рекомендовано, для багатьох слів).**
Відкрийте будь-який із файлів у `data/` (Excel, Блокнот або VS Code, кодування UTF-8) і додайте рядки.
Нові CSV-файли підключаються в `WORD_FILES` у `db.py`:

```csv
category,original,uk
travel,L'aeroporto,аеропорт
travel,Il biglietto,квиток
```

- `category` — код категорії латиницею без пробілів (`food`, `family`, `travel`…); `розділ_підтема` — підтема. Нова категорія
  з'явиться в меню автоматично; щоб вона мала красиву назву, додайте її в `CATEGORY_NAMES` у `texts.py`.
- `original` — італійське слово (разом з артиклем, якщо потрібно).
- `uk` — український переклад. Якщо в тексті є кома, візьміть поле в лапки: `"Mi scusi, dov'è?"`.
- Щоб додати переклад для російськ./англ. інтерфейсу, додайте в заголовок колонки `ru` та/або `en`
  і заповніть їх. Порожні комірки пропускаються.

Потім застосуйте зміни одним із способів:

1. **Перезапустіть бота** — при старті він сам синхронізує CSV з базою (нові слова додаються,
   змінені переклади оновлюються). На Render: закомітьте зміни в GitHub — бот перезадеплоїться.
2. **Без запуску бота:** `python seed.py` (використовує `DATABASE_URL` з `.env`).
   Для бази на Render вставте в `.env` її *External Database URL*.

> Видалення рядка з CSV **не видаляє** слово з бази — див. спосіб 3.

**Спосіб 2 — через самого бота (особисті слова одного користувача).**
Кнопка «➕ Додати слово» → слово → переклад. Слово зберігається тільки для цього користувача
в категорії «Мої слова» і для тієї мови навчання, яка обрана зараз.

**Спосіб 3 — напряму SQL** (psql / pgAdmin / Render → Database → Connect):

```sql
-- додати одне системне слово (бачать усі користувачі з українським перекладом)
INSERT INTO words (original, translation, translation_lang, learn_lang, category, owner_id)
VALUES ('Il biglietto', 'квиток', 'uk', 'it', 'travel', NULL);

-- виправити переклад
UPDATE words SET translation = 'білет'
WHERE original = 'Il biglietto' AND learn_lang = 'it' AND translation_lang = 'uk' AND owner_id IS NULL;

-- видалити слово
DELETE FROM words
WHERE original = 'Il biglietto' AND learn_lang = 'it' AND owner_id IS NULL;
```

## Припущення

- Італійські слова з CSV мають український переклад. Користувачі з російським/англійським
  інтерфейсом бачать для італійської лише 10 стартових слів, доки в CSV немає колонок `ru` / `en`.
- Типова мова навчання — англійська; перемикається на італійську через «🎓 Що вчимо».
  Стартові слова мають переклад на uk/ru/en. Для англійської з інтерфейсом «English»
  замість перекладу показується коротке англійське пояснення.
- Власні слова прив'язані до мови навчання, яка була обрана в момент додавання.
  Для старої БД міграція виконується автоматично при старті (існуючі слова стають англійськими).
- Часовий пояс розкладу «ранок/вечір» — `TZ_NAME` (за замовчуванням `Europe/Kyiv`).

## Змінні оточення

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `BOT_TOKEN` | — | токен від @BotFather |
| `DATABASE_URL` | — | рядок підключення до PostgreSQL |
| `GEMINI_API_KEY` | — | ключ Gemini API |
| `GEMINI_MODEL` | `gemini-3.8-flash` | модель Gemini. **Значення зі змінної оточення важливіше за код**: якщо в Render лишилась стара модель, бот використовуватиме її |
| `TZ_NAME` | `Europe/Kyiv` | часовий пояс для «ранок/вечір» і нічного режиму |
| `AI_WEEKLY_LIMIT` | `5` | AI-запитів на тиждень |
| `QUIET_HOURS_START` / `QUIET_HOURS_END` | `22` / `9` | нічний режим без сповіщень |

Якщо модель Gemini вказана неправильно або знята з підтримки (404), бот пробує `gemini-3.8-flash`,
а потім `gemini-3.7-flash`. Активна модель пишеться в лог при старті: `Gemini model: ...`.
